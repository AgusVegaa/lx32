# Bare-Metal Firmware Tests (LX32)

This folder validates the freestanding firmware path for both C and Rust on the
LX32K keyboard processor.

---

## C Tests (`programs/`)

Validates the minimum C-freestanding slice: integer arithmetic, pointer/MMIO
loads and stores, control flow, calls, and the six custom LX32K instructions.

| Program                         | Tests                                 | Expected exit |
|---------------------------------|---------------------------------------|---------------|
| `01_return42.c`                 | Minimal entrypoint                    | 42            |
| `02_pointer_store.c`            | Pointer dereference load/store        | —             |
| `03_call_chain.c`               | Direct call sequence and return       | —             |
| `04_branch_loop.c`              | Counted loop with branches            | —             |
| `05_compare_assign.c`           | Comparisons and conditional assigns   | —             |
| `06_pointer_walk.c`             | Pointer indexing and accumulation     | —             |
| `07_fibonacci_iter.c`           | Iterative Fibonacci                   | —             |
| `08_fibonacci_recursive.c`      | Recursive Fibonacci + deep stack      | —             |
| `09_custom_intrinsics.c`        | All six LX32K hardware instructions   | —             |

### Run (C)

```bash
# From the repository root:
make test-baremetal           # smoke — programs 01–04
make test-baremetal-deep      # extended — all programs
```

## Rust Firmware Tests (`rust_programs/`)

Parallel Rust `#![no_std]` programs that exercise the same code paths as the C
tests, compiled with the custom LX32 rustc fork.

| Program                          | Tests                                  | Expected exit |
|----------------------------------|----------------------------------------|---------------|
| `01_return42.rs`                 | Constant return                        | 42            |
| `02_pointer_store.rs`            | Stack array LOAD/STORE                 | 30            |
| `03_call_chain.rs`               | Multi-level function calls             | 8             |
| `04_branch_loop.rs`              | While-loop accumulator                 | 45            |
| `05_compare_assign.rs`           | Conditional subtraction                | 10            |
| `06_pointer_walk.rs`             | Iterator over stack array              | 15            |
| `07_fibonacci_iter.rs`           | Iterative fib(10)                      | 55            |
| `08_fibonacci_recursive.rs`      | Recursive fib(10) — stress stack       | 55            |
| `09_custom_intrinsics.rs`        | All six LX32K hardware instructions    | 0             |

### Prerequisites

Build the Rust compiler and LX32 sysroot once:

```bash
make setup-rust           # clone, build stage1 rustc, build libcore for LX32
```

This takes 20–40 minutes the first time.  Subsequent runs are incremental.

### Run (Rust)

```bash
make build-rust-firmware-tests   # compile only, no simulation
make test-rust-firmware           # compile + run on RTL simulator
```

### Build the keyboard firmware

```bash
make build-firmware               # builds pulsar_pac keyboard example for LX32
make check-pac                    # type-check pulsar_pac on the host (fast)
```

## Shared infrastructure

| File          | Purpose                                              |
|---------------|------------------------------------------------------|
| `crt0.S`      | Baremetal entry point (`_start` → `main`)            |
| `link.ld`     | Memory map: 4 KB RAM at `0x00000000`                 |
| `crt0.o`      | Assembled `crt0.S` (auto-generated by build scripts) |

---

## Notes

- C programs use `-ffreestanding -fno-builtin -nostdlib`.
- Rust programs use `#![no_std] #![no_main]`; `_start` comes from `crt0.S`.
- The `rt` feature of `pulsar_pac` provides its own `_start` (replaces `crt0.S`).
- Both C and Rust programs write their exit code to `0xFFFFF004` (simulator halt).
